## Syntax highlighting

HTML, CSS, JavaScript and TypeScript are now coloured, detected by file extension (`.html` `.htm` `.css` `.js` `.mjs` `.cjs` `.ts` `.mts` `.cts`). Inside an HTML page, `<style>` and `<script>` bodies are coloured as CSS and JavaScript. Dark mode and Increase Contrast work automatically.

- **Colour never touches your file.** A highlighted document saves byte-identical, registers no undo, and closing it asks nothing.
- **Typing stays responsive.** Parsing is incremental, and every keystroke runs under an 80 ms budget. A file the budget can't finish — deep nesting, an unbalanced bracket — is shown plain rather than freezing the editor, and colour returns once the text parses again.
- **Size limits:** CSS up to 128 KB, everything else up to 64 KB. Minified files are not highlighted.

## Fixed

- **Revert to Saved** did not reload the text on screen, so the next save wrote the pre-revert text straight back over the reverted file.

## Install

```sh
unzip SimpleEdit.zip
mv SimpleEdit.app /Applications/
xattr -dr com.apple.quarantine /Applications/SimpleEdit.app
open /Applications/SimpleEdit.app
```

**The `xattr` line is required.** The app is ad-hoc signed, so macOS reports *"SimpleEdit is damaged and can't be opened"* without it — that means "not signed by a registered developer", not corrupted.

Universal binary: Apple Silicon and Intel.
